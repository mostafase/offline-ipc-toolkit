# Accessibility

The IPC Starter Kit aims to help healthcare teams use the same basic workflows on a shared computer, on a supported phone, or on paper. The interface offers six languages, including right-to-left Arabic. Printable forms provide a paper option where the digital workflow is impractical.

## Environments and current limits

The maintainer has reported successful use on Windows and Android. Storage, download, and print behavior can vary by browser and by how a local HTML file is opened. Consult the [device guide](docs/DEVICE-TESTING.md) for tested setups and local checks. The [printable field kit](field-kit/index.html) is available for teams that need a paper workflow.

The project has no published formal WCAG conformance assessment. Feedback on keyboard navigation, screen readers, text enlargement, contrast, and mobile touch is welcome.

## Report a barrier

Choose **Accessibility barrier** under **Issues → New issue**. Tell us what task you tried, your device and browser, any assistive technology you used, and where you could no longer continue. Use fictional data in screenshots and examples.
