Scope & Reference Model Note [PR-01, PR-02, PR-03]: The IPC Starter Kit collects no patient or staff identifiers and stores only grouped monthly counts by area code and supply stock balances [HH-10, PR-02, PR-03]. This plan uses administrative, physical, and technical safeguard categories from the HIPAA Security Rule strictly as a practical reference model for local device and backup stewardship—it is not a legal claim of HIPAA compliance [PR-01]. Any future workflow that handles personal health information (PHI) requires a separate deployment-specific privacy and security review [PR-03].
