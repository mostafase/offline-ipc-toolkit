# Security policy

## Versions

Please try to confirm the issue on the [latest official release](https://github.com/mostafase/offline-ipc-toolkit/releases/latest). Include the version or commit in your report.

## Report privately

Open the repository's **Security and quality** tab, select **Advisories**, and choose **Report a vulnerability**. Include the affected feature, device and browser, the problem you observed, and its likely impact. Use a fictional example and share only the minimum details needed to understand the issue.

Keep potential vulnerabilities out of public issues and pull requests while the report is being reviewed. Leave out patient and staff information, real facility records, backups, and credentials. The maintainer will use the private report to discuss next steps.

Use GitHub Issues for ordinary bugs that have no security implications.
